2. Elektromagnit Modellar Tahlili: PhET & Vascak.cz

Teskari Muhandislik & Elektrodinamika Dekonstruksiyasi

Simulyatsiya kodini yaratishdan oldin xalqaro miqyosda e'tirof etilgan professional laboratoriyalar (PhET Interactive Simulations — Faraday's Law, Charges and Fields, Circuit Construction Kit hamda Vascak.cz Physics Animations — Coulomb's Law, Lorentz Force) Teskari Muhandislik (Reverse Engineering) metodologiyasi bilan dekonstruksiya qilinadi:

1. PhET "Faraday's Law" Modeli Dekonstruksiyasi

• Magnit Oqimi Dinamikasi: Doimiy magnit dipol maydoni $B(x) \propto \frac{\mu_0 m}{(x^2 + R^2)^{3/2}}$ orqali g'altak kesimidan o'tuvchi oqim integrallanadi: $$\Phi_B(t) = \int_{S} \vec{B}(t) \cdot \mathrm{d}\vec{A}$$ • Induksiyalangan E.Yu.K.: Magnit tezligi oshgan sari vaqt bo'yicha hosila keskin ortadi: $$\mathcal{E}(t) = -N \frac{\mathrm{d}\Phi_B}{\mathrm{d}t}, \quad I(t) = \frac{\mathcal{E}(t)}{R_{zanjir}}$$

2. PhET "Charges and Fields" Dekonstruksiyasi

• Superpozitsiya Maydoni: Fazoning har bir $(x, y)$ nuqtasidagi to'la maydon kuchlanganligi zaryadlarning vektor yig'indisidir: $$\vec{E}(\vec{r}) = \sum_{i=1}^N \frac{1}{4\pi\varepsilon_0} \frac{q_i}{|\vec{r} - \vec{r}_i|^3} (\vec{r} - \vec{r}_i)$$ • Ekvipotensial Sirtlar: $\Phi(\vec{r}) = \text{const}$ shartini qanoatlantiruvchi izochiziqlar gradientga perpendikulyar bo'ladi ($\vec{E} = -\nabla\Phi$).

3. Maydon va Zanjir Animatsiyasi Kodi: Claude 3.5 Sonnet

Coulomb Superposition, Faraday Induction & RLC Engine

Elektrodinamika simulyatsiyasini amalga oshirish uchun Claude 3.5 Sonnet bilan "Juftlikda dasturlash" sessiyasida elektrostatik maydon superpozitsiyasi, Faradey induksiyasi va RLC zanjirining differensial tebranish tenglamalarini yechuvchi yuqori unumdor JavaScript moduli yoziladi:

📐 Elektrodinamikaning Fundamental Tenglamalari:

1. Kulon maydoni superpozitsiyasi va potensial gradiyenti:

$$\vec{E}(\vec{r}) = \sum_{i=1}^N \frac{k_e q_i}{r_i^2}\hat{r}_i, \qquad \Phi(\vec{r}) = \sum_{i=1}^N \frac{k_e q_i}{r_i}, \qquad \vec{E} = -\nabla\Phi$$

2. Faradey elektromagnit induksiya qonuni va Lens qoidasi:

$$\mathcal{E} = -\frac{\mathrm{d}\Phi_B}{\mathrm{d}t} = -N \frac{\mathrm{d}}{\mathrm{d}t}\left( \int \vec{B}\cdot\mathrm{d}\vec{A} \right)$$

3. RLC o'zgaruvchan tok zanjirining majburiy tebranishlar tenglamasi:

$$L\frac{\mathrm{d}^2 q}{\mathrm{d}t^2} + R\frac{\mathrm{d}q}{\mathrm{d}t} + \frac{q}{C} = U_0 \cos(\omega t), \qquad Z = \sqrt{R^2 + \left(\omega L - \frac{1}{\omega C}\right)^2}$$

// 1. Elektrostatik Maydon Intensivligi va Potensialini Hisoblash
function calculateElectricField(x, y, charges, ke = 8.99e3) {
  let Ex = 0, Ey = 0, potential = 0;
  for (let c of charges) {
    const dx = x - c.x;
    const dy = y - c.y;
    const r2 = dx * dx + dy * dy;
    const r = Math.sqrt(r2);
    if (r > 4) {
      const E_mag = (ke * c.q) / Math.max(100, r2);
      Ex += E_mag * (dx / r);
      Ey += E_mag * (dy / r);
      potential += (ke * c.q) / r;
    }
  }
  return { Ex, Ey, potential, magnitude: Math.hypot(Ex, Ey) };
}

// 2. Faradey Elektromagnit Induksiya Qonuni va E.Yu.K. Integratori
function calculateFaradayInduction(magnetX, prevMagnetX, coilX, coilTurns, coilRadius, dt) {
  const dist = coilX - magnetX;
  const rEff = Math.max(30, Math.abs(dist));
  // Magnit dipol maydoni B ~ M / (r^2 + R^2)^(3/2)
  const B = 480000 / Math.pow(rEff * rEff + coilRadius * coilRadius, 1.5);
  const sign = dist > 0 ? 1 : -1;
  const flux = sign * B * (Math.PI * coilRadius * coilRadius * 0.001);

  // Faradey qonuni: E.Yu.K. = -N * (dPhi / dt)
  const prevDist = coilX - prevMagnetX;
  const prevREff = Math.max(30, Math.abs(prevDist));
  const prevB = 480000 / Math.pow(prevREff * prevREff + coilRadius * coilRadius, 1.5);
  const prevFlux = (prevDist > 0 ? 1 : -1) * prevB * (Math.PI * coilRadius * coilRadius * 0.001);

  const dPhi = (flux - prevFlux) / Math.max(0.001, dt);
  const inducedEmf = -coilTurns * dPhi * 0.12;
  return { flux, inducedEmf };
}

// 3. RLC O'zgaruvchan Tok Zanjiri Impedansi va Fazaviy Siljishi
function calculateRlcOscillation(R, L, C_micro, U0, freq, time) {
  const C = C_micro * 1e-6;
  const omega = 2 * Math.PI * freq;
  const Xl = omega * L;
  const Xc = 1 / (omega * C || 1);
  const Z = Math.sqrt(R * R + (Xl - Xc) * (Xl - Xc));
  const I0 = U0 / (Z || 1);
  const phi = Math.atan2((Xl - Xc), R);

  const u_t = U0 * Math.sin(omega * time);
  const i_t = I0 * Math.sin(omega * time - phi);
  return { u_t, i_t, I0, Z, phi };
}
