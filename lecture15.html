15-Modul: Yadro Fizikasi, Capstone Yakuniy Loyiha & 7 AI Pipeline

Yadro Fizikasi Qonuniyatlari va Yakuniy Mustaqil Loyiha (Capstone) Metodologiyasi

Radioaktiv yemirilish qonuni ($N(t)=N_0 e^{-\lambda t}$), Uran-235 zanjirli yadro bo'linishi (fission: $E=\Delta mc^2 \approx 200\text{ MeV}$) va termoyadroviy sintez (fusion: $^{2}\text{H}+^{3}\text{H}\rightarrow^{4}\text{He}+n+17.6\text{ MeV}$) jarayonlarini modellashtirish hamda talabaning mustaqil tanlagan fizik mavzusi bo'yicha to'liq 7 ta AI vosita (MagicSchool → PhET/Vascak → Claude 3.5 Sonnet → Google Antigravity → ElevenLabs/Muxlisa → Otter.ai → Undetectable AI) yordamida yakuniy mustaqil loyihani (Capstone) yaratish va himoya qilish metodologiyasi.

📋 15-Ma'ruza Rejasi va To'liq AI-Pipeline Konveyeri:

1. AI Diagnostika & Reja:
MagicSchool AI: ZPD va Blum taksonomiyasi asosida 3 klasterli individual yadro fizikasi va Capstone rejasi.
2. Teskari Muhandislik (PhET/Vascak):
PhET Nuclear Fission, Radioactive Dating va Vascak.cz modellarini dekonstruksiya qilish.
3. Simulyator Kodi (Claude 3.5 Sonnet):
Monte-Karlo yemirilishi, neytron ko'payish zanjiri ($k$), mass-defekt energiyasi va Tokamak plazmasi kodi.
4. Monitoring (Google Antigravity AI):
Barion/lepton sonlari saqlanishi, energiya-massa dreyfi $|\Delta E/E_0| < 0.0001\%$ va xavfsizlik auditi.
5. Baholash Rubrikalari (MagicSchool AI):
Capstone loyihani baholash uchun 5 ta mezonli 100 ballik shkala va himoya reglamenti.
6 & 7. Capstone, Sandbox & Manbalar:
Undetectable AI akademik halollik nazorati, dual-canvas sandbox va APA 7th manbalar.

1. Sun'iy Intellekt Uchun Diagnostika va Individual Reja

MagicSchool AI & Vygotsky ZPD

Yadro fizikasi mikrodunyosi ko'zga ko'rinmas kvant-yadro kuchlari ($10^{-15}\text{ m}$), stoxastik radioaktiv yemirilish, zanjirli yadro bo'linishi va yuqori energiyali termoyadroviy sintez jarayonlaridan iborat. MagicSchool AI yordamida Vygotskiy Yaqin Rivojlanish Zonasi (ZPD) asosida talabalar 3 ta kognitiv klasterga ajratilib, shaxsiylashtirilgan o'quv traektoriyasi shakllantiriladi:

3 Kognitiv Klaster Bo'yicha Individual Yadro Fizikasi & Capstone Traektoriyasi:

Klaster A: Boshlang'ich (Foundational)

Tavsif: Radioaktiv yemirilish qonuni ($N(t) = N_0 2^{-t/T_{1/2}}$), $\alpha, \beta, \gamma$ nurlanish turlari va yadro bog'lanish energiyasi tushunchasini o'zlashtiruvchi daraja.
AI Strategiyasi: PhET Radioactive Dating Game orqali stoxastik yemirilish egri chiziqlarini ko'rish va hisoblash.

Klaster B: Amaliyotchi (Core)

Tavsif: Uran-235 zanjirli bo'linishi ($^{235}\text{U} + n \rightarrow \text{Ba} + \text{Kr} + 3n + 200\text{ MeV}$), ko'payish koeffitsiyenti $k$ va reaktor boshqaruvi.
AI Strategiyasi: Claude 3.5 Sonnet orqali neytronlar kinetikasi va mass-defekt energiyasini hisoblovchi kod yaratish.

Klaster C: Tadqiqotchi / Capstone

Tavsif: Termoyadroviy sintez (D-T Tokamak plazmasi), mustaqil tanlangan murakkab fizik jarayonni noldan simulyatsiya qilish va uni to'liq ilmiy himoya qilish.
AI Strategiyasi: Barcha 7 ta AI vositani yaxlit pipeline konveyeriga birlashtirish va Undetectable AI bilan hisobot originalligini kafolatlash.

2. Teskari Muhandislik Tahlili: PhET & Vascak.cz

Reverse Engineering & Nuclear Model Deconstruction

Yadro fizikasi modellarini yaratishda xalqaro e'tirof etilgan laboratoriyalar (PhET Interactive Simulations — Nuclear Fission, Radioactive Dating Game, Alpha Decay hamda Vascak.cz — Radioactive Decay, Nuclear Reactor) teskari muhandislik orqali dekonstruksiya qilinadi:

1. PhET "Nuclear Fission"

• Bitta Yadro Bo'linishi: $^{235}_{92}\text{U} + ^{1}_0n \rightarrow ^{141}_{56}\text{Ba} + ^{92}_{36}\text{Kr} + 3 ^{1}_0n + 200\text{ MeV}$.
• Zanjirli Reaksiya: Neytronlarning geometrik ko'payishi $n(t) = n_0 k^{t/\tau}$ va boshqaruv sterjenlari dinamikasi.

2. PhET "Radioactive Dating"

• Stoxastik Yemirilish: Har bir yadro uchun $\Delta t$ vaqt oralig'ida yemirilish ehtimolligi $P = 1 - e^{-\lambda \Delta t}$.
• Izotopik Tahlil: Uglerod-14 ($T_{1/2} \approx 5730$ yil) orqali arxeologik, Uran-238 ($T_{1/2} \approx 4.47 \cdot 10^9$ yil) orqali geologik yoshni hisoblash.

3. Vascak.cz "Nuclear Reactor"

• Reaktor Termogidravlikasi: TVEL issiqlik ajratishi va sovutish konturi issiqlik balansi: $Q = \dot{m} c_p \Delta T$.
• Kritiklik Holati: $k = 1.000$ kritik, $k > 1$ o'ta kritik, $k < 1$ subkritik rejimlar.

Wieman, C. E., Adams, W. K., & Perkins, K. K. (2008). PhET: Simulations That Enhance Learning. Science, 322(5902), 682–683. https://doi.org/10.1126/science.1161948
Manba mazmuni: PhET simulyatsiyalarini loyihalash tamoyillari: ko'zga ko'rinmas jarayonlarni vizuallashtirish, darhol qayta aloqa beruvchi interaktiv boshqaruv va talabaning mustaqil tadqiqotini rag'batlantirish orqali konseptual tushunishni chuqurlashtirish.
Eslatma: PhET'ning Nuclear Fission, Radioactive Dating Game va Alpha Decay simulyatsiyalari eski Java versiyada mavjud; brauzerda (HTML5) ishlaydigan eng yaqin muqobil — Build a Nucleus (7-bo'limdagi jonli laboratoriya).

📐 Yadro Fizikasining Fundamental Formulalari:

1. Radioaktiv yemirilish qonuni:
$$N(t) = N_0 e^{-\lambda t} = N_0 2^{-t/T_{1/2}}, \quad A(t) = \lambda N(t)$$ 2. Mass-defekt va bog'lanish energiyasi:
$$\Delta m = [Z m_p + (A-Z)m_n] - M_{\text{yadro}}, \quad E_{\text{bog'}} = \Delta m c^2$$
3. Uran-235 bo'linish zanjirli reaksiyasi:
$$^{235}_{92}\text{U} + ^{1}_0n \rightarrow ^{141}_{56}\text{Ba} + ^{92}_{36}\text{Kr} + 3 ^{1}_0n + 200\text{ MeV}$$ 4. D-T termoyadroviy sintez:
$$^{2}_{1}\text{H} + ^{3}_{1}\text{H} \rightarrow ^{4}_{2}\text{He} + ^{1}_{0}n + 17.6\text{ MeV}$$

// 1. Stoxastik Monte-Karlo Radioaktiv Yemirilish Integratori
function simulateRadioactiveDecay(nuclei, lambda, dt) {
  const prob = 1 - Math.exp(-lambda * dt);
  let decayedCount = 0;
  for (let n of nuclei) {
    if (n.state === 'active' && Math.random() < prob) {
      n.state = 'decayed';
      decayedCount++;
    }
  }
  return { decayedCount, remaining: nuclei.filter(n => n.state === 'active').length };
}

// 2. Uran-235 Zanjirli Bo'linishi va Neytronlar Dinamikasi
function updateFissionChainReaction(nuclei, neutrons, controlRodDepth, dt) {
  let energyYield = 0;
  for (let i = neutrons.length - 1; i >= 0; i--) {
    const n = neutrons[i];
    n.x += n.vx * dt;
    n.y += n.vy * dt;
    n.life -= dt;

    // Boshqaruv sterjeni yutishi (Kadmiy / Bor)
    if (Math.abs(n.x - 290) < 16 && n.y < 30 + 220 * controlRodDepth) {
      n.life = 0;
    }

    // Uran-235 yadrosi bilan to'qnashuv
    for (let nucl of nuclei) {
      if (nucl.state === 'stable' && Math.hypot(n.x - nucl.x, n.y - nucl.y) < nucl.r + 4) {
        nucl.state = 'fissioned';
        energyYield += 200; // MeV
        // 3 ta yangi tezkor neytron ajralishi
        for (let k = 0; k < 3; k++) {
          const a = Math.random() * Math.PI * 2;
          neutrons.push({ x: nucl.x, y: nucl.y, vx: Math.cos(a)*180, vy: Math.sin(a)*180, life: 6.0 });
        }
        n.life = 0;
        break;
      }
    }
    if (n.life <= 0) neutrons.splice(i, 1);
  }
  return { energyYield, neutronCount: neutrons.length };
}

Metropolis, N., & Ulam, S. (1949). The Monte Carlo Method. Journal of the American Statistical Association, 44(247), 335–341. https://doi.org/10.1080/01621459.1949.10483310
Manba mazmuni: Monte-Karlo usulining asos soluvchi maqolasi: tasodifiy sonlar yordamida neytronlar ko'payishi kabi stoxastik jarayonlarni statistik modellashtirish. Yuqoridagi simulateRadioactiveDecay va updateFissionChainReaction funksiyalari aynan shu yondashuvga asoslangan.
