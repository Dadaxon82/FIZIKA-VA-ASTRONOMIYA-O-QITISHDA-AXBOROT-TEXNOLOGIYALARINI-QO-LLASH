8-Laboratoriya Mashg'uloti: AI Pair-Programming & Computational Physics

Sun'iy Intellekt Bilan Juftlikda Dasturlash (Pair-Programming) Orqali Elastik To'qnashuvlar va Vektor Arifmetikasiga Asoslangan Kichik Fizika Dvigateli Kodini Yozish

Kompyuter simulyatsiyalari va kompyuter o'yinlarining markaziy qismi — qattiq jismlar to'qnashuvini aniq hisoblovchi fizik dvigatel (Physics Engine) hisoblanadi. Mazkur laboratoriya mashg'ulotida 6-laboratoriyada tuzilgan kuchlar va harakat tenglamalari asosida 2D Vektor arifmetikasi, doiralar to'qnashuvini aniqlash, impuls skalyari ($J$) almashinuvi hamda yopishib qolish (sticky collision) muammosini bartaraf etuvchi to'liq dvigatel yaratiladi. Claude 3.5 Sonnet (yoki boshqa zamonaviy LLM) bilan juftlikda dasturlash (Driver / Navigator) metodologiyasida kod xatoliklari tuzatiladi, ChatGPT Code Interpreter (hozirgi nomi — ChatGPT'dagi ma'lumotlar tahlili vositasi) muhitida esa impuls va energiyaning saqlanish qonunlari sonli tekshiriladi.

📋 8-Laboratoriya Mashg'uloti Rejasi va Tahliliy Bosqichlari:

1. Diagnostika & Shaxsiy Reja:
TPACK va ZPD tamoyillari asosida 2D vektor arifmetikasi, impuls va elastik to'qnashuvlar bo'yicha diagnostik test hamda shaxsiy ta'lim traektoriyasi.
2. Fizika Dvigatelini Yozish:
Vector2D klassi, to'qnashuvni aniqlash, normal va tangensial tezliklar, impuls skalyari $J$ va massalar nisbati arxitekturasi.
3. Claude Bilan Juftlikda Debugging:
Driver va Navigator rollari; 4 ta kritik fizik nosozlik (vektorlarni skalyar qo'shish, sticky collision, energiya dreyfi, tunneling) auditi.
4. Code Interpreter Tekshiruvi:
Impuls va kinetik energiya saqlanishining sonli tekshiruvi: 10 000 ta tasodifiy to'qnashuv (Monte-Karlo) sinovi va xatoliklar taqsimoti.

1. Sun'iy Intellekt Uchun Kognitiv Diagnostika va Individual Ta'lim Trayektoriyasi

Fizika dvigatelini kodlash talabadan ham chuqur nazariy fizika (Nyutonning uchinchi qonuni, impuls va kinetik energiya saqlanishi, elastik va noelastik to'qnashuvlar dinamikasi), hamda 2D vektor arifmetikasi va obyektga yo'naltirilgan dasturlash (OOP) bilimlarini talab etadi. TPACK (Mishra & Koehler, 2006) va ZPD (Vygotskiy, 1978) konsepsiyalariga asoslangan quyidagi 4 ta diagnostik savol orqali talabaning kognitiv profili aniqlanadi va Claude 3.5 Sonnet bilan juftlikda ishlash uchun shaxsiy prompt generatsiya qilinadi.

2. Fizika Dvigatelini Claude Bilan Yozish: Vektor Arifmetikasi va To'qnashuvlar Dinamikasi

Kompyuter fizik dvigateli (Physics Engine) — tabiatning mexanik qonuniyatlarini raqamli muhitda diskret vaqt qadamlari orqali modellashtiruvchi dasturiy majmuadir. 6-laboratoriyada tuzilgan FBD (Erkin jism diagrammasi) kuchlar muvozanati endi dinamik to'qnashuv impulslari bilan boyitiladi.

2.1. 2D Vektor Arifmetikasi (Vector2D Class)

Fizik kattaliklar (koordinata $\vec{r}$, tezlik $\vec{v}$, tezlanish $\vec{a}$, kuch $\vec{F}$, impuls $\vec{p}$) yo'nalishga ega vektorlar bo'lgani sababli, skalyar $x, y$ o'zgaruvchilari o'rniga maxsus Vector2D klassi joriy etiladi:

  • Vektorlar yig'indisi va ayirmasi: $\vec{a} \pm \vec{b} = (a_x \pm b_x)\hat{i} + (a_y \pm b_y)\hat{j}$
  • Skalyarga ko'paytirish va bo'lish: $k \vec{a} = (k a_x)\hat{i} + (k a_y)\hat{j}$
  • Skalyar ko'paytma (Dot product): $\vec{a} \cdot \vec{b} = a_x b_x + a_y b_y = |\vec{a}| |\vec{b}| \cos\theta$
  • Modul (Uzunlik) va Normalizatsiya: $|\vec{a}| = \sqrt{a_x^2 + a_y^2}; \quad \hat{n} = \frac{\vec{a}}{|\vec{a}|}$
class Vector2D {
  constructor(x = 0, y = 0) { this.x = x; this.y = y; }
  add(v) { return new Vector2D(this.x + v.x, this.y + v.y); }
  sub(v) { return new Vector2D(this.x - v.x, this.y - v.y); }
  mult(s) { return new Vector2D(this.x * s, this.y * s); }
  div(s) { return s !== 0 ? new Vector2D(this.x / s, this.y / s) : new Vector2D(); }
  dot(v) { return this.x * v.x + this.y * v.y; }
  magSq() { return this.x * this.x + this.y * this.y; }
  mag() { return Math.sqrt(this.magSq()); }
  normalize() { const m = this.mag(); return m > 0 ? this.div(m) : new Vector2D(); }
}

2.2. To'qnashuvni Aniqlash va Impuls Yechimi (Impulse-Based Resolution)

Ikki doiraviy qattiq jism (markazlari $\vec{r}_1, \vec{r}_2$, radiuslari $R_1, R_2$) to'qnashuvi masofa orqali aniqlanadi:

$$\Delta \vec{r} = \vec{r}_2 - \vec{r}_1, \quad d = |\Delta \vec{r}| \le R_1 + R_2$$

To'qnashuv chizig'i bo'ylab birlik normal vektor (1-shardan 2-sharga yo'nalgan): $\hat{n} = \frac{\Delta \vec{r}}{d}$. Nisbiy tezlik: $\vec{v}_{rel} = \vec{v}_1 - \vec{v}_2$. Normal yo'nalishdagi tezlik proyeksiyasi: $v_n = \vec{v}_{rel} \cdot \hat{n}$. Agar $v_n > 0$ bo'lsa, jismlar yaqinlashmoqda va to'qnashuv yuz beradi.

Nyutonning tiklanish qonuni ($e \in [0, 1]$ tiklanish koeffitsiyenti bo'lib, $e=1$ mutlaq elastik, $e=0$ noelastik) va impuls saqlanishiga binoan, to'qnashuv impulsi skalyari $J$ quyidagi formula bo'yicha hisoblanadi (Hecker, 1997; Millington, 2010). Bu yerda $J \le 0$ chiqadi, ya'ni 1-shar $\hat{n}$ ga qarshi, 2-shar esa $\hat{n}$ bo'ylab itariladi (sharlar aylanmaydi va ishqalanish hisobga olinmaydi deb faraz qilinadi):

$$J = \frac{-(1 + e)(\vec{v}_{rel} \cdot \hat{n})}{\frac{1}{m_1} + \frac{1}{m_2}}$$ $$\vec{v}_1' = \vec{v}_1 + \frac{J \hat{n}}{m_1}, \quad \vec{v}_2' = \vec{v}_2 - \frac{J \hat{n}}{m_2}$$

2.3. Yopishib Qolishni Bartaraf Etish (Penetration & Overlap Resolution)

Diskret vaqt qadamli ($\Delta t$) simulyatsiyalarda to'qnashuv paytida jismlar bir-birining ichiga $\delta = (R_1 + R_2) - d$ masofaga kirib qoladi. Agar ularning pozitsiyasi to'g'rilanmasa va $v_n > 0$ (yaqinlashish) sharti tekshirilmasa, keyingi kadrda ham $d < R_1 + R_2$ bo'lib, impuls uzoqlashayotgan jismlarga qayta qo'llanadi va ular bir-biriga "yopishib", titrab qoladi.

Yechim — pozitsiyani massalarga teskari proporsional ravishda siljitish:

$$\Delta \vec{r}_1 = -\hat{n} \cdot \delta \cdot \frac{m_2}{m_1 + m_2}, \quad \Delta \vec{r}_2 = +\hat{n} \cdot \delta \cdot \frac{m_1}{m_1 + m_2}$$

3. Juftlikda Dasturlash va Debugging: Claude 3.5 Sonnet Bilan Hamkorlik

Juftlikda dasturlash (Pair-Programming) — ikki dasturchi bitta kod ustida ishlaydigan usul. Williams va boshq. (2000) tajribasida juftliklar yozgan dasturlar avtomatik testlardan ko'proq o'tgan, umumiy sarflangan vaqt esa biroz (taxminan 15% ga) oshgan. AI bilan juftlikda ishlash inson bilan ishlashning to'liq o'rnini bosmaydi: masalan, GitHub Copilot bo'yicha nazorat tajribasida vazifa 55,8% tezroq bajarilgan (Peng va boshq., 2023), biroq AI taklif qilgan kodni har doim o'zingiz tushunib, sinab ko'rishingiz shart. Ushbu laboratoriyada talaba Driver (amaliy kod yozuvchi va interfeysni boshqaruvchi), Claude 3.5 Sonnet esa Navigator (algoritm arxitekturasi, fizik qonunlarga muvofiqlik va nosozliklarni izlovchi mutaxassis) rolini bajaradi.

🔍 Fizika Dvigatellarida Eng Ko'p Uchraydigan 4 Ta Tipik Nosozlik va AI Auditi:

1-Nosozlik: Vektorlarni Skalyar Qo'shish Xatosi (Scalar Arithmetic Bug)

Matematik Xato

Alomati: Qiya to'qnashuvda jismlar noto'g'ri yo'nalishda sakraydi (masalan, faqat gorizontal bo'ylab), impuls vektori saqlanmaydi.
Sababi: Talaba vx1 = vx1 + J deb skalyar qiymat qo'shadi, holbuki impuls faqat normal vektor $\hat{n}$ bo'yicha yo'naltirilishi lozim.

2-Nosozlik: Sharlar Yopishib Qolishi va Titrashi (Sticky Collision Bug)

Geometrik Xato

Alomati: Kam tezlikdagi to'qnashuvda ikkita shar bir-birining ichidan chiqa olmay, markazda titrab qoladi va sekin aylanadi.
Sababi: Pozitsiya to'g'rilanmagan (overlap resolution yo'q) va $v_n > 0$ sharti tekshirilmagan. Keyingi kadrda ham masofa $d < R_1 + R_2$ bo'lib, dvigatel ularni yana qayta to'qnashdi deb hisoblaydi va uzoqlashayotgan sharlarni bir-biriga qaytarib itaradi.

3-Nosozlik: Energiya Dreyfi va "Portlashi" (Energy Drift / Explosion)

Integratsiya Xatosi

Alomati: $e = 1$ bo'lsa ham, vaqt o'tishi bilan to'liq energiya sekin (yoki keskin) ortib boradi, sharlar tobora tezlashadi.
Sababi: To'qnashuv impulsining o'zi $e = 1$ da energiyani saqlaydi, shuning uchun manba boshqa joyda: (1) og'irlik kuchi yoki prujina kuchlari oshkor Eyler usulida hisoblangan (x += v*dt dan keyin v += a*dt — energiya har qadamda ortadi, 4-laboratoriyaga qarang); (2) $J$ formulasida ishora yoki massa xatosi (masalan, $(1+e)$ o'rniga $2(1+e)$); (3) pozitsiyani to'g'rilash siljishi keyin tezlikka aylantirilgan. Yechim — Eyler-Kromer (yarim-oshkor) usuli va har bir qadamdan keyin $E_k$ ni kuzatib borish.

4-Nosozlik: Tunnel Effekti (Tunneling at High Velocity)

Integratsiya Xatosi

Alomati: Katta tezlikda harakatlanayotgan kichik shar devor yoki boshqa shar bilan to'qnashmasdan, uning ichidan to'g'ridan-to'g'ri o'tib ketadi.
Sababi: Bir kadr oralig'idagi siljish $\Delta r = v \cdot \Delta t$ to'siq qalinligidan katta bo'lgani sababli, oraliq kontakt holati hisoblanmay qoladi. Yechimi — Sub-stepping (kichik ichki qadamlarga bo'lish, shart: $v \cdot \Delta t_{sub} < R$) yoki uzluksiz to'qnashuv aniqlash (Continuous Collision Detection — to'qnashuv vaqtini analitik topish).

4. Fizik Qonunlar Algoritmi Tekshiruvi: ChatGPT Code Interpreter Muhitida Verifikatsiya

Fizika dvigatelining ilmiy ishonchliligi uning fundamental saqlanish qonunlariga (Kinetik energiya va To'liq impuls vektori) qanchalik qat'iy amal qilishiga bog'liq. ChatGPT Code Interpreter (keyinchalik "Advanced Data Analysis" deb nomlangan) Python muhitida to'qnashuv formulalarini 10 000 ta tasodifiy to'qnashuv (Monte-Karlo) asosida sinovdan o'tkazish va xatoliklar taqsimotini hisoblash imkonini beradi. Quyidagi skriptni o'zingiz ham ishga tushirib, AI bergan natijalar bilan solishtiring: $e = 1$ da impuls va energiya xatoligi faqat suzuvchi nuqta yaxlitlash darajasida (~$10^{-13}$) bo'lishi kerak.

🐍 ChatGPT Code Interpreter Uchun Python Matematik Verifikatsiya Skripti:

import numpy as np
import matplotlib.pyplot as plt

def test_elastic_collision_conservation(num_trials=10000):
    np.random.seed(42)
    # 1. Boshlang'ich parametrlar: massalar [0.5, 10.0] kg, tezliklar [-50, 50] m/s
    m1 = np.random.uniform(0.5, 10.0, num_trials)
    m2 = np.random.uniform(0.5, 10.0, num_trials)
    v1 = np.random.uniform(-50, 50, (num_trials, 2))
    v2 = np.random.uniform(-50, 50, (num_trials, 2))
    
    # Tasodifiy to'qnashuv normal vektori n (|n| = 1)
    angles = np.random.uniform(0, 2 * np.pi, num_trials)
    normal = np.column_stack([np.cos(angles), np.sin(angles)])
    
    # 2. Boshlang'ich saqlanish kattaliklari
    p_initial = (m1[:, None] * v1) + (m2[:, None] * v2)
    Ek_initial = 0.5 * m1 * np.sum(v1**2, axis=1) + 0.5 * m2 * np.sum(v2**2, axis=1)
    
    # 3. Nisbiy tezlik va impuls skalyari J (e = 1.0 mutlaq elastik)
    rel_vel = v1 - v2
    v_normal = np.sum(rel_vel * normal, axis=1)
    
    # Faqat yaqinlashayotgan to'qnashuvlar (v_normal > 0)
    valid = v_normal > 0
    m1, m2 = m1[valid], m2[valid]
    v1, v2 = v1[valid], v2[valid]
    normal = normal[valid]
    v_normal = v_normal[valid]
    p_initial = p_initial[valid]
    Ek_initial = Ek_initial[valid]
    
    e = 1.0 # Elastik tiklanish
    J = -(1.0 + e) * v_normal / (1.0 / m1 + 1.0 / m2)
    
    # 4. To'qnashuvdan keyingi tezliklar
    v1_final = v1 + (J[:, None] * normal) / m1[:, None]
    v2_final = v2 - (J[:, None] * normal) / m2[:, None]
    
    # 5. Yakuniy saqlanish kattaliklari
    p_final = (m1[:, None] * v1_final) + (m2[:, None] * v2_final)
    Ek_final = 0.5 * m1 * np.sum(v1_final**2, axis=1) + 0.5 * m2 * np.sum(v2_final**2, axis=1)
    
    # 6. Xatoliklar tahlili
    p_error = np.linalg.norm(p_final - p_initial, axis=1)
    Ek_error = np.abs(Ek_final - Ek_initial) / Ek_initial * 100 # %
    
    print(f"Muvaffaqiyatli sinovlar soni: {len(v_normal)}")
    print(f"Maksimal Impuls xatoligi: {np.max(p_error):.2e} kg*m/s")
    print(f"Maksimal Kinetik Energiya xatoligi: {np.max(Ek_error):.2e} %")
    
    return p_error, Ek_error

p_err, ek_err = test_elastic_collision_conservation()
