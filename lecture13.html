1. Sun'iy Intellekt Uchun Diagnostika va Individual Reja

MagicSchool AI & Vygotsky ZPD

Molekulyar fizika va termodinamika bo'limini o'rganishda talabalar ko'pincha mikroskopik (tasodifiy molekulalar to'qnashuvi, Maksvell-Bolsman tezlik taqsimoti) va makroskopik (bosim $P$, hajm $V$, harorat $T$, entropiya $S$) kattaliklar o'rtasidagi bog'liqlikni tushunishda jiddiy kognitiv qiyinchilikka duch keladilar. MagicSchool AI yordamida Vygotskiy Yaqin Rivojlanish Zonasi (ZPD) va Blum taksonomiyasi asosida 3 ta kognitiv klaster bo'yicha individual traektoriya shakllantiriladi:

3 Kognitiv Klaster Bo'yicha Individual Termodinamika Traektoriyasi:

Klaster A: Boshlang'ich (Foundational)

Tavsif: Ideal gaz qonunlari ($PV = \nu RT$), Mendeleyev-Klapeyron tenglamasi va izoprotsesslarni ($T=\text{const}$, $V=\text{const}$, $P=\text{const}$) o'zlashtiruvchi daraja.
AI Strategiyasi: PhET Gas Properties orqali bosimning molekulalar urilish soniga bog'liqligini ko'rish va 1-darajali hisoblash mashqlari.

Klaster B: Amaliyotchi (Core)

Tavsif: Maksvell-Bolsman tezlik taqsimoti, $v_{rms} = \sqrt{\frac{3 k_B T}{m}}$ va termodinamikaning 1-qonunini ($Q = \Delta U + A$) hisoblay oluvchi daraja.
AI Strategiyasi: Claude 3.5 bilan Box-Muller stoxastik algoritmi kodi, $P-V$ egri chiziq ostidagi yuzani integrallash va Karno F.I.K. hisoblash.

Klaster C: Tadqiqotchi (Advanced)

Tavsif: Stoxastik fluktuatsiyalar, Bolsman $H$-teoremasi, entropiya o'sish qonuni ($\mathrm{d}S \ge 0$) va $T-S$ faza fazosi tahlili.

2. Termodinamika Simulyatsiyalari Tahlili: PhET & Vascak.cz

Teskari Muhandislik & MKT Dekonstruksiyasi

Fizika dasturlashni boshlashdan oldin talaba tayyor professional simulyatsiyalarni (PhET Interactive Simulations — Gas Properties, States of Matter hamda Vascak.cz Physics Animations — Carnot Cycle, Iso-processes) 2-ma'ruzada o'rganilgan Teskari Muhandislik (Reverse Engineering) metodologiyasi yordamida dekonstruksiya qiladi:

1. PhET "Gas Properties" Modeli Dekonstruksiyasi

• Mikroskopik Bosim Mexanizmi: Gaz bosimi datchigi vaqt birligi ichida idish devorlariga urilgan zarrachalarning impuls uzatish integrali orqali hisoblanadi: $$\bar{P} = \frac{\sum_{i} 2 m |v_{x,i}|}{A \cdot \Delta t}$$ • Harorat va Tezlik Masshtabi: Idish tagidagi isitgich/sovutgich zarrachalar tezligini termal faktor bilan yangilaydi: $$v_{new} = v_{old} \cdot \sqrt{\frac{T_{target}}{T_{current}}}$$

2. Vascak.cz "Carnot & Cycles" Dekonstruksiyasi

• Izoprotsesslar va Sikllar: Porshen harakati va $P-V$ egri chiziqlari Puasson tenglamasi ($PV^\gamma = \text{const}$) va Boyl-Mariott qonuni ($PV = \text{const}$) bilan boshqariladi.
• Karno Sikli F.I.K.: $$\eta_{max} = 1 - \frac{T_C}{T_H} = \frac{A_{net}}{Q_H}$$

3. Stoxastik Jarayonlar Simulyatsiyasi Kodi: Claude 3.5 Sonnet

Box-Muller Transform, Maxwell-Boltzmann & Elastic Ensemble

Termodinamikada molekulalarning tartibsiz issiqlik harakatini modellashtirish uchun oddiy tekis tasodifiy sonlar yetarli emas. Claude 3.5 Sonnet bilan "Juftlikda dasturlash" sessiyasida Box-Muller algoritmi orqali 2D Maksvell-Bolsman tezlik taqsimotini shakllantiruvchi yuqori unumdor stoxastik dvigatel kodi yoziladi:

📐 Box-Muller Transformatsiyasi va 2D Maksvell Taqsimoti:

Ikkita mustaqil tekis taqsimlangan $u_1, u_2 \in (0, 1]$ sonlaridan nol o'rtacha qiymatli va $\sigma = \sqrt{\frac{k_B T}{m}}$ dispersiyali normal (Gaus) tasodifiy sonlar generatsiya qilinadi:

$$z_0 = \sqrt{-2 \ln u_1} \cos(2\pi u_2) \cdot \sigma, \qquad z_1 = \sqrt{-2 \ln u_1} \sin(2\pi u_2) \cdot \sigma$$

Natijada zarrachalar tezligi $v = \sqrt{v_x^2 + v_y^2}$ analitik 2D Maksvell-Bolsman (Rayleigh) taqsimotiga qat'iy bo'ysunadi:

$$f(v) = \frac{m}{k_B T} v \exp\left( -\frac{m v^2}{2 k_B T} \right)$$

// 1. Box-Muller Transformatsiyasi: Normal (Gaus) tasodifiy sonlar
function randomGaussian(mean = 0, stdev = 1) {
  const u1 = Math.max(1e-7, 1 - Math.random());
  const u2 = Math.random();
  const z0 = Math.sqrt(-2.0 * Math.log(u1)) * Math.cos(2.0 * Math.PI * u2);
  return z0 * stdev + mean;
}

// 2. Maksvell-Bolsman ansamblini harorat T bo'yicha initsializatsiya qilish
function createThermalGasEnsemble(N, T, kB, mass, width, height, topY) {
  const particles = [];
  const sigma = Math.sqrt((kB * T) / mass) * 22;

  for (let i = 0; i < N; i++) {
    particles.push({
      x: 15 + Math.random() * (width - 30),
      y: topY + 15 + Math.random() * (height - topY - 30),
      vx: randomGaussian(0, sigma),
      vy: randomGaussian(0, sigma),
      radius: 3.5,
      mass: mass
    });
  }
  return particles;
}

// 3. Devorlar va porshen bilan elastik to'qnashuv impulslari
function updateGasWallCollisions(particle, left, right, top, bottom, dt) {
  let impulse = 0;
  particle.x += particle.vx * dt * 60;
  particle.y += particle.vy * dt * 60;

  if (particle.x - particle.radius < left) {
    particle.x = left + particle.radius;
    particle.vx = -particle.vx;
    impulse += 2 * particle.mass * Math.abs(particle.vx);
  }
  if (particle.x + particle.radius > right) {
    particle.x = right - particle.radius;
    particle.vx = -particle.vx;
    impulse += 2 * particle.mass * Math.abs(particle.vx);
  }
  if (particle.y - particle.radius < top) {
    particle.y = top + particle.radius;
    particle.vy = -particle.vy;
    impulse += 2 * particle.mass * Math.abs(particle.vy);
  }
  if (particle.y + particle.radius > bottom) {
    particle.y = bottom - particle.radius;
    particle.vy = -particle.vy;
    impulse += 2 * particle.mass * Math.abs(particle.vy);
  }
  return impulse;
}

4. Bosim – Hajm (P-V) va Harorat – Entropiya (T-S) Grafiklarini Chizish: ChatGPT (Code Interpreter)

Phase Space, Carnot Efficiency & Entropy Planes

Termodinamik sikllarning (Karno, Stirling, Otto, Dizel) foydali ish koeffitsiyentini tahlil qilishda holat diagrammalari eng kuchli analitik vosita hisoblanadi. ChatGPT Code Interpreter (Advanced Data Analysis) yordamida $P-V$ (Bosim-Hajm) va $T-S$ (Harorat-Entropiya) faza fazosi egri chiziqlari aniq matematik integrallanadi:

📈 Bosim – Hajm ($P-V$) Tekisligi va Bajarilgan Ish ($A$)

• Yopiq siklda bajarilgan to'liq foydali ish egri chiziq bilan chegaralangan maydonga teng: $$A_{sikl} = \oint P \, \mathrm{d}V$$ • Karno sikli: $A_{net} = \nu R (T_H - T_C)\ln\left(\frac{V_2}{V_1}\right)$
• Izotermik ish: $A_{12} = \nu R T_H \ln\left(\frac{V_2}{V_1}\right)$
• Adiabatik ish: $A_{23} = \frac{\nu R}{\gamma - 1}(T_H - T_C)$

🌡 Harorat – Entropiya ($T-S$) Tekisligi va Entropiya ($S$)

• Termodinamikaning 2-qonuni va Klauzius tengsizligi bo'yicha entropiya o'zgarishi: $$\mathrm{d}S = \frac{\delta Q_{qayt}}{T}, \qquad Q_{sikl} = \oint T \, \mathrm{d}S$$ • $T-S$ tekisligida Karno sikli mukammal to'g'ri to'rtburchak shaklini oladi.
• Gorizontal chiziqlar: Izotermalar ($T=\text{const}$); vertikal chiziqlar: Izoentropalar ($S=\text{const}$).

# ChatGPT Code Interpreter: Carnot & Stirling Cycles Phase Plotter

import numpy as np
import matplotlib.pyplot as plt

R = 8.314
Th, Tc = 600, 300   # Issiq va sovuq manbalar (K)
gamma = 1.4         # Ikki atomli gaz (gamma = Cp/Cv)
V1, V2 = 1.0, 2.0   # Boshlang'ich hajmlar

# Karno 4 holat nuqtalari
V3 = V2 * (Th / Tc)**(1 / (gamma - 1))
V4 = V1 * (Th / Tc)**(1 / (gamma - 1))
eta = 1 - Tc / Th
print(f"Nazariy Karno F.I.K.: {eta*100:.2f}%")

v_iso_h = np.linspace(V1, V2, 100)
p_iso_h = R * Th / v_iso_h

v_adiab_exp = np.linspace(V2, V3, 100)
p_adiab_exp = (R * Th / V2) * (V2 / v_adiab_exp)**gamma

plt.style.use('dark_background')
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 5))
ax1.plot(v_iso_h, p_iso_h, color='#38bdf8', label='1-2 Izoterma (Th)')
ax1.plot(v_adiab_exp, p_adiab_exp, color='#fbbf24', label='2-3 Adiabata')
ax1.set_title('Karno Sikli: P-V Diagrammasi')
ax1.set_xlabel('Hajm V (m³)')
ax1.set_ylabel('Bosim P (Pa)')
ax1.grid(alpha=0.3)
ax1.legend()
plt.tight_layout()
plt.show()
